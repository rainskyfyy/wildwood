# assets/ — 美术、音频、字体资源

按类型分子目录:**不直接放 Godot 源文件**(.aseprite / .ase / .wav),由 CI 脚本(M1.13)统一导出为引擎可识别的 `.png` / `.ogg` 后再 import。

## 子目录

| 子目录   | 内容                                         | 状态        |
|----------|----------------------------------------------|-------------|
| `art/`   | 像素画(.aseprite 源 + 导出 PNG)             | M1.12 起填充 |
| `audio/` | 音效 / 音乐(.wav / .ogg)                    | 待规划      |
| `fonts/` | 像素字体(.ttf / .otf / .woff2)              | 待规划      |

## 美术硬约束(方案 §4.5 PR 评审 5 项)

1. **剪影测试**:纯黑剪影必须能识别身份;主角 vs 怪物剪影差异度 ≥ 80%
2. **色板测试**:违例色(不在 24 色板内且肉眼可分辨)= 0
3. **网格测试**:像素中心必须落在整数网格上,误差 ≤ 0px(不允许子像素)
4. **抗锯齿测试**:边缘不允许中间灰阶,硬切或像素阶梯
5. **动画流畅度**:同动作帧数前后版本变化 ≤ 20%

校验脚本由 M1.13 落地,跑在 CI 流水线。

## 调色板(24 色)

按方案 §4.1,色板分 5 类,**色比硬约束:暖色 ≥ 70%、冷色 ≤ 15%、中性色占剩余**:

- 暖色基底(红 / 橙 / 黄)
- 自然色(草绿 / 树棕 / 泥灰)
- 警示色(血红 / 警戒黄)
- 冷色点缀(夜蓝 / 紫黑)
- 中性色(米白 / 深褐)

> 禁止纯黑(用 `#1a1410`)、禁止纯白(用 `#f4e4c1`)。

详细色板 schema 由 M1.6 在 `core/abstract/assets/palette.json` 落地。
