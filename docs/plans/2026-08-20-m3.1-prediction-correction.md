# M3.1 客户端预测 + 服务端校正 ★ 关键路径

> **For Agent:** 高级开发工程师直接端到端实施。本计划按 TDD 垂直切片,每条任务 2-5 分钟。

**Goal:** 实现"客户端本地立即执行 + seq 序号 + 服务端 50ms tick 校验 + 偏差 > 32px 时 100ms 插值校正 + 校正期间被校正实体隐藏 100ms"

**Architecture:**
- **协议层**(M1.5 已完成,不改动):`C2S_PlayerInput.input_seq` → `S2C_WorldDelta.acked_input_seqs` + `entity_updates`
- **服务端权威**(M3.1 增量):Go 端 `Room.AuthState` 维护玩家权威位置 + 输入队列;50ms tick 推进 + 广播
- **客户端预测+校正**(M3.1 增量):
  - 通用层(Python stdlib):`Predictor`/`Interpolator` 纯函数,pytest 覆盖
  - 引擎层(GDScript 1:1 镜像):`wildwood_predictor.gd` / `wildwood_interpolator.gd` + SEMANTICS.md

**Tech Stack:** Go 1.22 (server) + Godot 4.3 GDScript (client) + Python 3.10+ (通用层逻辑镜像) + stdlib unittest (测试)

## 验收对照

| 验收项 | 落地位置 |
|--------|----------|
| ① 本地输入 ≤ 50ms 反馈 | predictor.predict_and_send(): 60Hz physics_process 内立即执行 |
| ② 校正 100ms 平滑无跳帧 | interpolator.display_pos_at(): start→target 100ms 线性插值 |
| ③ 校正期间被校正实体隐藏 100ms | interpolator.is_hidden_at(): 0~100ms 返回 True |
| ④ 服务端 tick 50ms 校时偏差 < 16ms | m31_tick_timing_test.go: 1000 tick p99 测量 |
