## 关键设计决策

### 1. 共享元素库(任务书硬约束)

`core/abstract/biome/elements.py` 定义 4 类基础元素,每类只声明**视觉骨架**(如「树:垂直 32×32 + 树冠 16×16 + 树干 8×24」),**不**含任何具体像素。具体像素由 M2.14 资产清单统一出,M2.7 数据结构留 `source_ref: "m2.14.tree.birch"` 引用。

```python
# 共享元素库 — 只定义视觉骨架
SHARED_ELEMENTS = ["grass", "rock", "tree", "mushroom"]

# 群系 = 共享元素 + 主色 + 组合比例 + 特征资源/怪物
biome = {
    "id": "forest",
    "shared_elements": SHARED_ELEMENTS,           # 4 群系共用
    "primary_color_hex": "#7d8b4d",                 # 仅替换主色
    "density": {"tree": 0.18, "rock": 0.04, ...},  # 仅替换组合比例
    "signature_resources": ["m2.14.berry_bush"],    # 引用 M2.14 资产
    "signature_monsters": ["m2.14.spider"],
}
```

### 2. 9 宫格流式加载(内存 -60%)

- 9 宫格:玩家所在 1 中心 + 8 邻居 = 9 块(3×3)
- 每块 32×32 网格,每网格 32px → 1 块 = 1024×1024px = 32×32 元素
- 内存:每块 ≈ 1MB(假设 200 元素平均),9 块 ≈ 9MB
- 全图 vs 9 宫格:全图 100×100 = 10000 块 = 10000MB;9 宫格 9MB → -99.91%(远大于 -60%)
- 验收 ≥ -60% 达标

### 3. 相机过渡 0.5s

- 状态机:IDLE → TRANSITION_OUT(0.25s,alpha 1→0) → SWAP → TRANSITION_IN(0.25s,alpha 0→1) → IDLE
- 边界判定:玩家中心从群系 A 中心 → 群系 B 中心时触发
- 验收测试:过渡总时长 ∈ [490ms, 510ms]

### 4. 复用 M2.14(2026-08-20 拍板)

所有视觉资源(主角 28 帧、10+ 资源、5+ 工具、5+ 建筑、20+ UI)由 M2.14 统一出,M2.7 数据 schema 留 `source_ref` 指向 M2.14 ID。M2.7 **不**内置任何像素/帧。
