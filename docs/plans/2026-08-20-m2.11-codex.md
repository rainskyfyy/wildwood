# M2.11 图鉴系统 Implementation Plan

> **For Agent:** 高级开发工程师实施

**Goal:** 实现双 Tab 图鉴（生物 + 物品），未解锁灰显 + ??，击杀/采集自动解锁，5Hz 队伍共享；不依赖 M2.10 战斗系统也能单测通过。

**Architecture:**
- 数据层：CodexDatabase（静态预置 30+ 条目）+ CodexState（per-room 解锁字典）
- 协议层：4 个新消息（CodexSync 全量 / CodexDelta 增量 / CodexQuery 客户端拉取 / CodexView 开关）
- 服务端：CodexStore 嵌入 Hub，5Hz 独立 ticker 广播增量
- 客户端：WildwoodCodex 控制器 + CodexView UI（双 Tab + 列表 + 详情卡）
- 关键边界：M2.10 战斗系统只对接 `Hub.UnlockCodex(playerID, entryID)` 一个钩子点

**Tech Stack:** Protobuf 3 · Go 1.22 (gorilla/websocket + protobuf) · GDScript (Godot 4.3) · Python 3.10+ (数据 schema 文档生成)

## 关键决策（已定）

1. **5Hz 频率**：服务端独立 ticker 200ms 一次，不是 20Hz 的子集 — 简化版，M3.1 接管后会改
2. **CodexSync vs CodexDelta**：Join 时全量（DB+unlocked）；后续 5Hz 只广播 unlocked 增量
3. **CodexDatabase 静态预置**：编译时 hard-code 30+ 条目；M2.14 美术资产到位后只改 sprite_key
4. **5Hz vs 5Hz×N 房间**：5Hz 独立 ticker 但每房间独立维护 dirty set，避免无关房间干扰
5. **不依赖 M2.10**：通过 `Hub.UnlockCodex(playerID, entryID)` 单点接入；M2.10 完成后只需一行代码对接
